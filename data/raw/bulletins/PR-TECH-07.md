# Technical Advisory PR-TECH-07

**Issuer:** PackRight Systems Pvt. Ltd.  
**Related Products:** PKG-120  
**Date:** 2026-01-15  
**Subject:** Carton Feeder and Tape Specifications for CartonPro 1200

PKG-120 is semi-automatic: an operator positions and feeds an already erected carton, and the machine applies tape to close it. It does not erect cartons.

Compatible tape width is 48–72 mm.

Tape is not included unless listed on the purchase order.
